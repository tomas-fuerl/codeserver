## Extensionvertrag und Lockpfad

`extensions.txt` bleibt die unveränderte Wunschliste; Kommentar- und
Leerzeilen werden ignoriert, wirksame Zeilen sind unversionierte
`publisher.extension`-IDs. `extensions.lock.txt` enthält kompakt genau neun
wirksame Zeilen im Format `publisher.extension@version`, keine Kopfzeile,
URL, private Gallery, Metadatenzeile, ungepinnte Zeile oder Duplikate. Jede
gewünschte Extension besitzt genau einen Lockeintrag.

`scripts/sync-extensions.sh` bestimmt sein Repository-Root aus dem eigenen
Pfad und verwendet standardmäßig exakt die Rootdatei `extensions.lock.txt`.
Ein Override ist nur über `CODESERVER_EXTENSIONS_LOCK_FILE` zulässig und muss
absolut sein. Fehlende, unlesbare, ungültige und doppelte Lockeinträge werden
vor einer Installation abgewiesen. In diesem Task wurde keine Extension
installiert oder synchronisiert.
